# 👤 Biodata

Welcome to my Biodata project! This project presents my personal, educational, professional, and contact information in a simple and well-structured format.

## 👩‍💻 About the Project

This Biodata is designed to provide a clear overview of my personal profile, education, skills, interests, and other relevant information.

The project focuses on:

- Clean and simple design
- Easy-to-read information
- Proper content organization
- Professional presentation
- Responsive layout

## ✨ Features

- 👤 **Personal Information** – Basic personal details
- 🎓 **Educational Details** – Academic qualifications
- 💻 **Technical Skills** – Programming and technical skills
- 🛠️ **Projects** – Academic and personal projects
- 🌟 **Hobbies & Interests** – Personal interests
- 📞 **Contact Information** – Ways to connect with me
- 📱 **Responsive Design** – Suitable for different screen sizes
- 🎨 **Simple UI** – Clean and professional presentation

## 🛠️ Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality (if applicable)
